# Compiler Design Practicals

A collection of Compiler Design lab practicals covering fundamental parsing techniques and grammar analysis.

##  Practical List

| No. | Practical | Description |
|---|---|---|
| 1 | FIRST and FOLLOW | Calculation of FIRST and FOLLOW sets for a given grammar. |
| 2 | LL(1) Predictive Parser | Implementation of a predictive parser using an LL(1) parsing table. |
| 3 | LR(0) Parser | Construction of LR(0) items and parsing table for syntax analysis. |
| 4 | SLR(1) Parser | Implementation of Simple LR parsing using LR(0) items and FOLLOW sets. |
| 5 | CLR(1) Parser | Construction of Canonical LR(1) items and parsing table. |
| 6 | LALR(1) Parser | Implementation of Look-Ahead LR parsing by merging compatible LR(1) states. |
| 7 | Operator Precedence Parser | Construction of precedence relations and parsing of input expressions. |

##  Requirements

- A compatible compiler or interpreter
- Visual Studio Code (recommended)
- Git for version control

##  Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/DivyankBaluni/Compiler-Design-Practicals.git
   ```

2. Open the project folder in Visual Studio Code.

3. Navigate to the practical you want to execute.

4. Run the corresponding implementation.

##  Learning Objectives

- Understand context-free grammars and their properties.
- Calculate FIRST, FOLLOW, FIRSTVT and LASTVT sets.
- Understand top-down and bottom-up parsing techniques.
- Construct and interpret parsing tables.
- Explore different parser construction methods.
- Understand syntax analysis in compiler design.
